Not one verdict. A sequence of small semantic decisions. Each answer determines the next question—or stops the process without changing anything.

The feedback is the conversation
“No, I meant the public API docs.”

The agent loaded an internal-docs skill and edited the wrong files. Agent Watch brings that correction, recent turns, and tool outcomes to Jev as structured evidence—not as instructions to obey.

The core idea
if → if → if → draft → if → if

Jev answers bounded Noul and Choice questions. The controller supplies the options for each stage, checks probabilities, and stops on weak evidence. Jev never writes code.

The conditional chain

Six stages. Many safe exits.

01
Jev · Noul · absolute question
Would a harness change likely fix this recurring issue?

Recent user inputs, agent turns and tool results are the evidence. Require a high yes probability on two distinct settled turns.

EXAMPLE → repeated scope correction
YES → continueAsk which component.
NO / UNCLEAR → stopKeep observing.
02
Jev · Choice · observed targets
Which harness component contributed?

Options come from real project-local files seen in context or tool use: a skill, instruction, prompt, setting or extension. Include none.

EXAMPLE → .pi/skills/docs/SKILL.md
CLEAR WINNER → continueBuild its change menu.
NONE / CLOSE CALL → stopNo forced blame.
03
Jev · Choice · target-specific directions
What kind of improvement fits?

A skill might need a narrower trigger or clearer instructions. These choices are created for the selected component, not drawn from one universal list.

EXAMPLE → narrow the skill’s activation rule
CLEAR DIRECTION → continueDraft alternatives.
NONE / CLOSE CALL → stopDo not guess.
04
Headless Pi + deterministic code
Draft concrete alternatives. Filter them.

A separate tool-free Pi call proposes 2–3 different replacements for one allowed file. Code rejects invalid syntax, duplicate contents, forbidden paths and stale base files.

EXAMPLE → two valid skill descriptions survive
VALID DIFFS → continueOffer them to Jev.
NO VALID DIFF → stopLive file stays untouched.
05
Jev · Noul then Choice
Is any candidate suitable? Which exact diff wins?

The Noul permits “no change.” Only if it passes does Choice select an ID from the validated alternatives. Pi cannot select its own proposal.

EXAMPLE → candidate_2, not a vague instruction
SELECTED → applySnapshot, write, log.
NO / UNCLEAR → stopNothing changes.
06
Later turns · Jev + hard limits
Did the change help?

Later conversation and tool outcomes are compared with the original failure. Jev may answer better, worse or unclear; cost, time and tool-error caps remain code rules.

EXAMPLE → no more public/internal docs confusion
BETTER → keepRecord the outcome.
WORSE → rollbackRestore saved content.
UNCLEAR → watch longer.
Why so many questions?

Each one has a narrower job. A Choice cannot invent a missing option; a Noul can say there is no good reason to change anything.

What is saved?

Evidence IDs, questions, probabilities, option sets, the selected diff and rollback history live locally. Applied changes appear in .agent-watch/changes.md.

What is not solved yet?

Thresholds are uncalibrated. Different later tasks do not prove cause and effect. Generated extension code needs stronger isolation before sensitive use.
