Agent Watch / Architecture

An agent harness
that improves itself.

The conversation is the feedback. Jev makes a sequence of bounded decisions; a separate Pi run drafts possible improvements; code controls what can change.

PI FIRST · LOCAL-FIRST · OPEN SOURCE
01 / Whole system

From conversation to verified change

EvidencePi sessionUser messages, corrections, assistant turns, tool results, skills.
CaptureObserverPi extension sends redacted events to a local daemon.
FocusSliding windowCurrent goal plus recent, relevant turns.
DecideJev treeAsk one semantic question, then branch to the next.
GenerateHeadless PiDrafts alternative edits without touching live files.
ControlApply + ledgerJev picks a diff; code validates, snapshots, applies, or rolls back.
↶Later user messages and tool outcomes feed the next window. If the change helps, keep it; if it regresses, restore the snapshot.
02 / Inside the Jev tree

Semantic “if” statements, one after another

01 · NOUL

Change warranted?

Is the problem in the harness, rather than an unfinished task?

No / unclear → observe
02 · CHOICE

Where?

Choose among components actually present: a skill, instruction, tool setting, prompt, extension.

No clear target → observe
03 · CHOICE

How?

Pick a direction specific to that component and this failure.

No suitable direction → observe
04 · PI + CODE

Draft & filter

Pi drafts 2–3 concrete alternatives. Code rejects forbidden or invalid edits.

Nothing valid → observe
05 · NOUL + CHOICE

Which edit?

Jev checks whether any draft is suitable, then chooses an exact validated diff—or none.

No / ambiguous → observe
06 · JEV + CODE

Did it help?

Jev compares later behavior; hard limits check cost, errors and duration.

Worse → rollback
03 / Boundaries

The model judges. Code enforces.

Only project-local harness files

No application source or global Pi configuration. A selected diff must match its saved base file.

Every action is traceable

.agent-watch/changes.md records evidence, Jev decisions, the diff and rollback history.

Failure leaves Pi working

Jev unavailable? No edit. Unclear choice? No edit. User changed a file? Never overwrite it.
